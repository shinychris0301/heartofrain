PLAYBACK ENTRY POINTS
PowerUpPlaybackGallery (HeartOfTheRain.M07):
  SelectEntry(index)   Select from Data/PowerUpGalleryCatalog.json.
  Replay()            Restart the selection and play it.
  Seek(seconds)       Pause at a time in the current selection.
  StepFrame(+1/-1)     Step the active board timeline or animation clip.
  SetBoardSize(c, r)   Rebuild the demonstration board with the chosen dimensions.
  playing, speed, loop, autoAdvance are public playback controls.
  Duration, PlaybackTime and EntryCount expose review state.

BoardReactionReview (HeartOfTheRain.M07):
  Assign an existing bound Demo prefab, configure kind/columns/rows/origin,
  targetColor/seekerTarget/rocketVertical/showBlockers, then call Rebuild().
  Set play=true for self-driven looping, or set externallyDriven=true and call
  Sample(seconds) from an external clock. The gallery owns this clock itself.
  CurrentPlan exposes the deterministic timeline and its tile/effect records.
  PlayGoldenCombination(kind, cell, vertical, color) starts kinds 17 through 20.

Example using a bound standalone board component:
  review.columns = 9;
  review.rows = 11;
  review.PlayGoldenCombination(ReviewKind.GoldenSeekerBomb,
                              new Vector2Int(4, 5));

RenderedSpritePlayer (HeartOfTheRain.M05):
  Supply atlas Texture2D, manifest TextAsset and the supplied unlit Material.
  Initialize() creates shared sprites from manifest rectangles.
  Play(clipName) plays independently; Completed reports a finished nonlooping
  clip. Sample(clipName, seconds) provides deterministic external playback.
  Set playOnEnable=false before activating externally driven objects.
  No runtime meshes or lights are required for the baked depth appearance.

ASSET IMPORT CONTRACT
Keep texture dimensions at least as large as their manifest atlasWidth/Height.
The supplied .meta files disable mipmaps, retain alpha and use clamp wrapping.
Do not repack or resize an atlas without rebuilding its frame rectangles.
Frame x/y values use Unity's bottom-left origin; topLeftY is used by the Python
review renderer. pixelsPerUnit and frame canvas extents already encode scale.
Use white sprite tint. The supplied unlit materials preserve the authored art;
tile glow is a separate property block during orb targeting. Review mobile
texture compression and memory on target devices before choosing release
import settings; no performance or pipeline certification is included.
The gallery uses all pages for review. A release level can load its needed
effect families instead of carrying the complete review catalog at once.

SHARED RULES PRESERVED
Folded seeker wings during rest/charge; open wings in flight. Body scale 1.4.
Curved travel, height crest, banking and an accelerating final dive.
Golden pairs are visibly created even when eligible targets run out; unassigned
seekers dissolve with stars and deal no damage. Targets are reserved so flights
do not duplicate a target unnecessarily. Refill waits for every carrier and
its payload, including overlapping bomb blasts.
Ordinary tile destruction uses the approved 14 pieces (8 medium, 6 small),
approved enlarged fragment scale and original tile hues. Wood has its own
breakup. Stars remain layered separately from the fragment sprites.
No Golden + Golden combo is added. Super Orb has no standalone gameplay kind.

LIVE GAME INTEGRATION BOUNDARY
ReviewPlan.Build and GoldenSeekerComboPlan.Build currently create a seeded
demonstration layout. They are executable choreography references, not a live
match-3 board-state API. In the game, supply actual tile IDs, obstacles and
eligible targets to your gameplay resolver; feed the resolved target cells
and activation times into the corresponding playback tracks. The included
plan data provides origin, power lifetimes, flight start/travel/targets, effect
start/duration/transforms, conversion times, hit times, and fall destinations.
Apply gameplay hits once when their event times are crossed; do not re-apply
damage from a visual sample or while scrubbing. Reserve targets before launch,
coalesce overlapping damage, and release the refill barrier after the final
flight and payload. Use the game's own gravity/refill and objective resolver.
The demo's grid generation, refill and score-free review loop can then be
replaced without altering the approved sprites or animation clip definitions.

VALIDATION COMMANDS
Unity menu: Heart of the Rain > Power-Ups > Validate Complete Package.
Runs the prior C# gates, Golden target-exhaustion checks, 18 Bomb fixtures,
gallery inventory and effect references. This gate is supplied but was not
executed in the packaging environment.
Offline:
  python Source/validate_final.py /absolute/path/M33_PowerUps_Final_R1
The final audit expects the restored M32_GoldenSeekerCombos_R1 sibling as the
approved baseline. The packaged Final_Report.json records the completed run.
Source/render_final.py builds review stills and a three-worker, 60-fps film.
Source/package_final.py assembles .unitypackage and ZIP with payload hashes.
