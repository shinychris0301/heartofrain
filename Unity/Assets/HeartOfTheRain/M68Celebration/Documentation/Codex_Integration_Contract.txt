BAKED ATLAS OPTION
- Read Data/Dariya_Celebration.json. Page indices and rectangles are explicit.
- Each page is 3104 x 3104 with 4px gutters; each frame is 768 x 768.
- rect_top_left uses PNG coordinates. rect_unity_bottom_left is the equivalent
  bottom-left rectangle; do not invert twice. Pivot is (0.5,0.5).
- PNGs contain straight alpha, sRGB color, all character/effect opacity fades.
  Do not multiply by the character opacity a second time.
- Textures: max size 4096, no resizing, clamp, bilinear, no mipmaps, Read/Write
  off, alpha transparency enabled. Included metadata uses uncompressed review
  quality, with the same TextureImporter convention as the existing project.
- The textures are Texture2D assets plus explicit rectangles, not auto-sliced
  Sprite subassets or a ready-made Animator controller. Codex may create Sprite
  subassets or use the existing atlas renderer from the declared rectangles.
- All 14 uncompressed RGBA pages occupy about 515 MiB before overhead. This is
  reference/export quality, not a mobile residency target. Do not keep them all
  resident by default. Prefer the mesh data for production, or validate texture
  compression and page loading on target devices. No mobile benchmark is claimed.

MESH OPTION — SAME AUTHORED CHARACTER MOTION, SMALLER TEXTURE SET
- Mesh/Dariya_Mesh_Clip.json defines every binary layout and file reference.
- 5,070 vertices, 6,448 triangles, 210 position samples, little-endian data.
- Positions: float32 [frame][vertex][xy], normalized square, x right / y up.
  Subtract (0.5,0.5), multiply by the square size, then place at its center.
  Position file has 8,517,600 bytes. Linear interpolation between adjacent
  samples is allowed; never recalculate different arm pivots in runtime code.
- UVs: float32 [vertex][uv], bottom-left origin; texel centers are included.
- Indices: int32 [triangle][3], clockwise in XY. Verify culling/material setup.
- Base texture is Art/Dariya_Master.png. Blink texture is the matched
  Mesh/Dariya_Blink_Texture.png, which changes only the eye regions.
- Blend base and blink texture RGBA with the sampled blink weight, then apply
  the sampled opacity to alpha. Preserve the original texture colors, use
  transparent unlit rendering, and do not apply scene lighting or tinting.
- Effects_Timeline.json provides per-frame halo center, normalized size,
  angle in degrees, opacity and particle positions/sizes/angles/opacities.
  Effect coordinates use TOP-LEFT origin. Convert y to 1-y for Unity XY.
  Positive image angles are counterclockwise as viewed on screen.
- Effects_Design.json supplies particle ids, star flags and confetti colors.
  Star particles use Art/Celebration_Star.png; other particles are small solid
  rectangles. height_ratio sets each rectangle's flutter. All effects render
  behind the character, in order: halo, stars/confetti, character.
- The mesh data is portable asset data, not a bundled Unity runtime component.
  Validate visual agreement with the baked clip once the player is integrated.
