2. FIX THE OFFER BUG AT ITS SOURCE
Search the integrated presenter and quote service for CanAffordContinue, canContinue, hasOffer, GetQuote, wallet checks,
and the literal 'No extra moves available'. Separate offer eligibility from affordability.
WRONG: quote = coins >= cost ? GetQuote(attempt) : null;
WRONG: available = quote != null && wallet.Coins >= quote.CoinCost;
RIGHT: quote comes from attempt eligibility / continue policy, independent of the wallet.
A quote-fetch timeout, offline response, disabled/unconfigured client fixture or null while loading is not confirmed
unavailability. Render Loading or RecoverableError; only an explicit policy/cap response renders ConfirmedUnavailable.
Do not enable Data/Continue_Config.example.json for production merely to make this screenshot look correct.

Typical binding sketch (adapt to the actual lifecycle / authority):
  flow.SetQuote(validatedQuote); // Do not discard this because coins < quoted cost.
  view.Render(ContinueOfferViewModel.Ready(validatedQuote), wallet.Coins, localizedLabels, locale);
  view.PlayRequested += () => Dispatch(flow.PlayOn(wallet.Coins));
  view.ShopRequested += () => Dispatch(flow.OpenCoinShop());
  view.EndConfirmationRequested += () => OpenExistingExitConfirmation();
  view.RetryQuoteRequested += () => RequestFreshQuoteForSameAttempt();
  view.PackRequested += () => OpenExistingShopAtVerifiedProduct(productId);

Dispatch OpenShop immediately through the existing shop with entryContext=continueAttempt.
Dispatch RequestMovePurchase using the persisted idempotent operation ID and trusted transaction service from R2.
Set view.SetTransactionPending(true) synchronously before dispatch; keep it locked through unknown outcomes.
Do not let a wallet snapshot arrive during a pending purchase and re-enable the modal.
Do not pass late quote callbacks from another attempt, account, or earlier request into the view.
When the authority confirms a move purchase, reconcile wallet and the SAME board, then hide the overlay.
Do not call Load/Retry/NextLevel or reset powers, goals, RNG, score, history, or obstacles.
Close Shop -> refresh balance/quote and restore Continue. Verified coin credit never auto-spends on moves.
Back/close in Continue -> existing exit confirmation, not immediate life loss. Settled abandonment charges one life once.
Dispose/unsubscribe handlers when the view/attempt is released; do not add another subscription each time it reopens.
The view's callbacks are deliberately not connected to a fake wallet or purchase simulator.
