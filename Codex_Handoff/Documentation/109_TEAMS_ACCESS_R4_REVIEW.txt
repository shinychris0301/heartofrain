PACKAGE AND SCOPE

The standalone Unity package and ZIP-embedded Unity package are byte-identical.
All 151 Unity payloads match the ZIP's Unity tree. The 484 declared manifest
entries match their sizes and SHA256 hashes; all 69 runtime PNGs pass PNG chunk
CRC and complete IDAT/row validation. All 77 delivered Unity GUIDs are unique
and do not collide with the frozen pre109 project. Package proofs are static
illustrations, not Unity/device captures.

The five R4 designs cover Find, Create, badge selection, team details before
joining and details for members. The live Teams component now uses the supplied
painted artwork and existing shared navigation. It retains actual member chat,
global/regional rankings, reporting, leadership transfer and pending-command
recovery. The package's sample teams, values and fabricated profiles are not
used as live data. The earlier approved108 navigation and106 objective icons
are unchanged.

The current service creates teams for free, accepts names of 2 to 32 Unicode
scalars, supports open membership and returns its configured capacity. Example
100-coin fees, 24-character limits, minimum levels and restricted team types
are not introduced. Scores, weekly help and online presence that are absent
from the service are not fabricated. A nonmember cannot see the private member
roster. The member invite action offers an explicit copy of team name and ID;
it does not automatically send a message.

Twelve R4 emblems are durable team metadata. The picker applies a draft only
on Choose and Close discards the unconfirmed selection. Existing teams default
to the raindrop. Search is bounded, Unicode-normalized and filtered on the
server before cursor paging, with exact team-ID lookup. A confirmed server
response remains authoritative for membership; failed and unknown mutations
retain protected recovery and visible feedback.

The new sprite container is loaded when the Teams page first uses R4 art,
not by the Home startup asset. It references the actual rendered roles and
the 12 composed badges; duplicate authoring masters and unused emblem variants
are not referenced. Minified detailed art uses mipmaps/trilinear filtering;
bordered slices use their role-specific settings and documented sprite borders.
The package's 149,621,808-byte all-PNG RGBA estimate excludes mipmaps and is an
upper-bound arithmetic figure, not an actual device memory measurement. First
open and resident texture/GPU cost still require device profiling.
