IMPLEMENTED_AND_EDITOR_VERIFIED; actual Android/device acceptance remains open.
The owner explicitly requested the original Home navigation size/style rather
than the smaller inset presentation from review106. This supersedes only review106 navigation
geometry. Its enlarged uniform objective artwork remains unchanged.

BEHAVIOR

For supported normal layouts (dock width at least 320 logical units), the icon,
selection plate, label boxes and selected-tab vertical relationship match the
exact pre106/105 source. The outer dock dimensions and reserved height remain
unchanged. Artwork/GUIDs/palette and navigation actions are preserved.

The centered group uses the original icon footprint S and column width cw:
original gap G = cw - S; new gap = 0.95 G; new pitch = S + 0.95 G.
Each visual center is dockCenter + (index-2)*pitch. This reduces the gap by 5%
without scaling icons or reducing touch columns. Touch targets retain their
original full-size equal columns. The whole dock/art/target group moves down
by up to 4 logical units, clamped to the available bottom margin.

The original taller/protruding selected-tab style is restored intentionally.
It is no longer subject to review106's smaller-frame blue-interior criterion. The
106 stationary selection-frame/tint and centered icon press feedback remain;
pressing does not alter hit bounds. Labels return their original 18-unit boxes.

When an extreme UI override produces a dock narrower than 320 logical units,
the bounded review106 compact fallback is retained. This prevents negative icon sizes
from the original cw-22 formula. Full-page extreme-zoom scrolling/content
separation remains outside this navigation-only correction.
