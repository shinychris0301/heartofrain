Behavior and rules
Teams Mail now has a server-backed inbox, unread badge, independent mark-read, scrollable detail, reward claim, empty/loading/offline/error/expired/full/pending states, and recovery controls. Cached text remains readable while offline; claims require reconnection and server eligibility. Marking read never grants a reward. Server expiry is authoritative. Coin/life bundles are claimed atomically; if all lives do not fit in the wallet the whole bundle is deferred. An uncertain claim retains the protected operation and exposes check/retry; subsequent retry uses the same command, with no client-side grant. Confirmation feedback waits for the authoritative wallet refresh. If the player leaves or is removed after earning a reward, the still-valid entitlement remains available through the owner-only Saved Team Rewards route; former team text and roster are not exposed. User approved this rule. Long text is wrapped, previews use two lines, and modal content scrolls.

Server implementation provides an idempotent internal issuance method for a future authorized source, with no player-facing issuance endpoint. No producer, leader-sending feature, automatic message, real reward amount, price or expiry schedule was invented. Inbox contents and rewards require a trusted issuer and a hosted configured service; server-supplied title/body localization is also an open source integration. Backend/TEAM_MAIL_UPGRADE111.txt documents the separately backed, stopped-owned schema12-to13 staging upgrade; no production authority was migrated.
