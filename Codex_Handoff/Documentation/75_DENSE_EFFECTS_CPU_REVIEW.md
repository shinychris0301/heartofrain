## Changes

`BoardModel.cs` builds snapshots using reusable private sort scratch, direct stable merging of piece references and stable insertion ordering for the small goal set. Every returned snapshot still owns fresh arrays and copied bodies/goals. ID ties retain dictionary enumeration order; goal ordering retains the current culture comparer. Scratch references are cleared after copying. Constructor preparation reserves a small bounded scratch set; this is reduced repeated work, not allocation-free gameplay. Matching, validation, RNG, gravity rules, durable transactions and newborn-power immunity are unchanged.

Development-only model counters identify snapshot, validation, footprint validation, matching, gravity, activation, planning and legal-query work. The counters default off and do not exist in release players. Times are inclusive and must not be summed; footprint validation does not measure every footprint query inside planning. `CascadeTimingProbe` can request a separate model-stage diagnostic run without changing the normal timing fixtures.

`BoardPlayback.cs` constructs the authored active-cell set once per Build when a fall first needs it, then shares that immutable set among the turn's fall phases. Geometry-free callers retain their per-phase before/after union. Single-leg route enumeration uses the original arithmetic directly instead of allocating a temporary leg and list. The scheduler, route geometry, contact timing and public motion records are unchanged by these allocation changes.

`M46AtlasBank.cs` reuses direct frame-entry slots after resolving an atlas clip. Slots refer only to entries owned by the existing sprite dictionary. Eviction and disposal invalidate a slot before destroying its sprite; lookup still updates the same frame and texture recency. Loop, hide, hold, dimensions, resource loading, cache budgets, pinning and the checkpoint 74 warmup race fix are preserved.

`EffectMeshBatcher.cs` caches a sprite geometry's immutable texture instance ID, compares the same texture/order group key and retains each slot's deterministic triangle prefix. Upload selects only the active prefix after shrink, empty and regrow frames. Geometry, UVs, colors, material, grouping order, depth, `Mesh.Clear(false)` and the 32-slot reserve remain unchanged. The renderer does not reduce authored debris, particles, effect counts or artwork quality.

`LocalCascadeContinuation.cs` adds a guarded terminal case before an unchanged Playing settlement. Every retimed flight must finish inside its owner; only ordinary landing history may continue into the same idle board. The verified extension covers natural commands on levels 14, 31 and 33 in addition to the existing level 4 case. Their native net schedule savings versus checkpoint 74 are 60, 95 and 200 ms. Only one continuation is permitted per turn. Power, advanced-obstacle, terminal-state, conflicting-route and unresolved-ownership guards remain in place.

An independent read of the unchanged live input/presentation path confirms that Busy remains set through the settled step and history survives acceptance of the next command. A newly moving body intentionally takes ownership from its old decorative landing. Rapid second input during that remaining squash is not part of the new video controls, so this review does not establish a visually continuous transition for every rapid follow-up gesture.
